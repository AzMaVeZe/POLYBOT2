# PadelZit share cards

Ready-to-post promo images for the app, in two languages and two shapes.

| File | Language | Size | Use |
|------|----------|------|-----|
| `card-he-landscape.png` | Hebrew | 1200×630 | WhatsApp/Facebook link preview (also wired as the site's og:image) |
| `card-he-square.png` | Hebrew | 1080×1080 | Instagram post, WhatsApp status |
| `card-en-landscape.png` | English | 1200×630 | Link preview / X / Facebook |
| `card-en-square.png` | English | 1080×1080 | Instagram post, WhatsApp status |

Each `.html` is the source; re-render with a headless browser at the size above
if you want to tweak text or colours. Palette matches the app
(navy #0f172a, sky #38bdf8, gold #fbbf24, tennis-green ball).
